# RISE HR Portal

A minimalist, high-performance HR Management System built with **Next.js 15**.

## 🚀 Quick Start

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Copy `.env.example` (or create `.env.local`) with your Supabase, Airtable, and Google OAuth credentials.

3. **Run the development server**:
   ```bash
   npm run dev
   ```

---

## 🛠 Features
- **Leave Management**: Submission & Approval workflows.
- **Announcements**: Real-time social board.
- **Audit Logs**: Administrative event tracking.
- **Insights**: System-wide metrics and reporting.
- **Cron Jobs**: Daily digests and reminders.

For full documentation and setup guides, please refer to the [Main README](../README.md) in the project root.
